# ADR-0006: sqlc による SQL クエリ生成

- 状態: Accepted
- 日付: 2026-11-27

## Context

モジュールの SQL リポジトリには、クエリ文字列と `Scan` の実装が重複していた。これらを手書きで保守すると、スキーマ変更時にクエリと Go 型の不整合を見逃しやすい。

## Decision

- SQL クエリの定義と Go コード生成に sqlc を使う。
- `sqlc.yaml` でモジュールごとの schema と query、生成先を明示する。
- 生成コードは各モジュールの `repository` パッケージにコミットし、実行時に sqlc を必要としない。
- リポジトリは生成されたクエリを呼び出し、ドメイン型への変換と `sql.ErrNoRows` の変換だけを担当する。
- マイグレーションは既存の埋め込み SQL ランナーを継続して使う。

## Consequences

- SQL とスキャン処理の重複が減り、`sqlc generate` でスキーマ変更の影響を検出できる。
- sqlc は生成時の開発ツールであり、実行時の Go 依存は増えない。
- 現在の `?` プレースホルダーと整合する SQLite 方言を sqlc の生成対象とする。
